# Tsk — Developer Portfolio

A simple, responsive portfolio for Julius Castillejo (Tskk-dev), featuring selected web development, tool development, and emulation projects.

## Preview

Open `index.html` in a browser. No build or installation is required.

To use a local server, run `python -m http.server 8000` in this folder, then visit `http://localhost:8000`.

## Files

- `index.html` — portfolio content and contact links
- `style.css` — responsive styles
- `script.js` — project category filters
- `favicon.svg` — site icon

## Host on GitHub Pages

Upload these files to the root of the repository's `main` branch. Keep `.nojekyll` alongside `index.html`.

In the repository, open **Settings → Pages**. Under **Build and deployment**, select **Deploy from a branch**, choose **main** and **/(root)**, then click **Save**.

GitHub displays the published website address on that Pages settings screen after deployment completes. Use a public repository with GitHub Free; private repository hosting requires an eligible paid plan.
